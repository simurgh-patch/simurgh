# 已批准开发计划与完成条件

## 固定决定

- 项目 simurgh 独立开发，个人＋AI，按技术关卡而非硬交期推进。
- Android/iOS ARM64 真机，面向公开商店，先真机后渠道验证。
- 官方 Flutter/Dart fork；热更新核心全链路自行实现，通用密码库、数据库、网络库、差分算法允许复用。
- 普通业务 Dart 代码不需要注解或手工桥接，允许配置、SDK、构建命令接入。
- 后台下载、下次进程冷启动生效；不做运行中堆栈和对象迁移。
- 自己团队使用，单组织、多应用、成员权限；首期不做公共 SaaS、计费、Kubernetes。
- 不修改 oa-app 或 Vue OA。任何兼容性样本需在本目录独立创建。

## 目标架构（尚未实现的部分不能标成可用）

| 模块 | 技术与职责 |
| --- | --- |
| 编译及运行时 | C++/Dart，基线 AOT＋变更字节码＋启动时链接 |
| 更新器 | Rust，经 C ABI 接入引擎，下载/验签/原子激活/回退 |
| CLI/SDK | Dart，构建、发布、查询、下载、健康确认 |
| 服务 | Go，PostgreSQL，S3 兼容存储，隔离 Ed25519 签名进程 |
| 控制台 | Vue 3＋TypeScript＋Element Plus，独立工程 |
| 部署 | Compose，外部 HTTPS 入口，开发存储 MinIO |

Application → Release → Patch → Deployment。补丁不可变且绑定精确基线；部署独立签名并单调递增。回滚是新部署指向旧补丁，不倒退部署代次。所有补丁可直接从原始基线安装。默认 staging/stable，晋级同一制品而不重编译。

原生插件、权限、引擎、打包资源变动要求整包发布，CLI 默认拒绝越界补丁。混合运行必须处理内联、去虚拟化、常量折叠、类型推断和字段偏移假设；基线与变更代码跨调用、异常、GC、泛型边界保持语义一致。

## 性能验收

同源码、设备和环境比较 official/custom_base/custom_patch。固定 form/list/navigation/animation/async：冷启动与帧耗时 P95 增幅≤10%，峰值内存增幅≤15%。每组启动至少30次，帧/内存至少5轮；Profile只定位问题。热点解释执行性能独立报告，不承诺所有函数同速；结论有波动时重测。

## M3 预定行为

状态为 downloaded→verified→pending→booting→healthy/bad。保留基线、最近健康补丁与待激活补丁。启动前运行原生恢复逻辑。默认首帧且存活30秒为启动健康，可选业务确认；明确加载/致命错误下次启动回退，不明中断连续两次后保守回退。问题补丁需新签名部署代次才能重试。业务数据库迁移不自动逆转。

## M4–M7 预定接口与约束

- CLI：doctor/init/release/patch/preview/promote/rollback/status；JSON输出及稳定退出码。
- SDK：checkForUpdate/downloadUpdate/currentPatch/updateState/reportHealthy；不强杀应用、不运行中替换代码。
- API：/v1 管理面；POST /v1/updates/check、POST /v1/telemetry/batch；制品独立下载。
- 客户端采用随机安装ID，不存广告或硬件标识；应用ID不是秘密，签名才是信任边界。
- 角色：admin/publisher/reader；生产发布和上传分权、记录审计。
- 灰度收缩不自动卸载已生效补丁，撤回独立操作；首版人工扩量，事件口径证明后才实现自动熔断。
- 错误事件30天、聚合/审计365天，配置可调整；保护生产基线及被引用补丁。
- 私钥只进入签名进程；令牌不进入配置文件；不依赖隐藏URL保护补丁。
- 首版负载基准100 RPS持续30分钟，P95<200ms、5xx<0.1%；注明实际测试硬件，不把它当作容量承诺。

每轮交付：可运行产物、复现测试、性能数据（没有则明确未测）、失败项、下一关卡。真实设备、可用构建卷、签名账号为外部资源依赖，缺少时记录阻塞，不伪造通过。
